# FURY HUB Bot v0.1

Discord-панель для FURY HUB.

Первая версия: команда /fury, выпадающее меню «Главная / План на рейд / Задачи / Взрыв / Протект / Состав / сайт» и подключение к общей Supabase.

## Запуск
1. Скопировать .env.example в .env
2. Заполнить DISCORD_TOKEN, DISCORD_GUILD_ID и SUPABASE_KEY
3. npm install
4. npm run register
5. npm start

Не добавляй .env и Discord token в GitHub.
